# Production readiness checklist

- [ ] `flutter pub get`
- [ ] `flutter analyze`
- [ ] `flutter test`
- [ ] Build Android release APK/AAB
- [ ] Test backup and restore
- [ ] Test PDF/printing
- [ ] Test invoice cancellation and inventory restoration
- [ ] Verify reports against sample data
- [ ] Create production backup before deployment

Completed invoices should be **cancelled**, not physically deleted.
